# Rebolusyon

A Pusoy Dos (Filipino Big Two) card game for the browser. Play against three bots with their own habits, in two modes:

- **Rebolusyon**: house rules, where Four of a Kind flips the card order and comebacks stay alive to the last round.
- **Klasiko**: straight Pusoy Dos, played out from 1st place down to the Talo.

## Run it

```bash
npm install
npm run dev     # local dev server
npm run build   # production build in dist/
npm test
```

Built with React, TypeScript and Vite. Deploys to Netlify via `netlify.toml`.
